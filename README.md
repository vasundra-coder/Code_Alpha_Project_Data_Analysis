# Mental Health and Lifestyle EDA

This project analyses the Sleep Health and Lifestyle dataset and creates cleaned data, summary tables, statistical tests, and eight charts. The statistical p-values use a normal approximation, appropriate for this 374-record exploratory dataset.

## Run

1. Install dependencies:

   ```powershell
   py -m pip install -r dataset/output/requirements.txt
   ```

2. From the project root, run:

   ```powershell
   py dataset/output/mental_health_analysis.py
   ```

All generated files are saved to `output/`. The source dataset remains unchanged.
